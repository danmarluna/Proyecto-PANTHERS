La programación visual con interfaz gráfica es una forma de crear programas que tienen elementos visuales con los que el usuario puede interactuar, en lugar de usar únicamente una consola de texto. ¿Qué significa "programación visual"? En muchas materias, Programación Visual con Interfaz Gráfica se refiere a aprender a crear programas mediante: Una ventana. Componentes visuales. Eventos. Código que responde a las acciones del usuario..
